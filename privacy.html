Privacy Policy

mpuploader · last updated: October 5, 2026

What this application is

mpuploader is a personal, non-commercial tool. It is used exclusively by its developer to upload technical log files from his own research camera traps to a folder in his own Google Drive. It has no other users.

Google user data the application accesses

The application uses the Google Drive API (scope https://www.googleapis.com/auth/drive) through the rclone command line tool. It uses this access only to create and write files inside one designated folder of the developer's own Google Drive. It does not read, analyze or use any other content of the account.

What the uploaded files contain

The uploaded files are technical logs of the camera trap devices (timestamps, device host names, battery charge level, software status and error messages). They contain no personal data of third parties.

Storage, sharing and retention

  • Access credentials are stored only on the developer's own devices (the camera traps and his own computer).
  • No data is collected by, sent to, or shared with any third party. There is no analytics, no advertising and no data sale.
  • Access can be revoked at any time via the Google Account permissions page; uploaded files can be deleted at any time in Google Drive.

Google API Services User Data Policy

mpuploader's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
